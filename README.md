# 长江雨课堂连续播放助手
主要针对北京理工大学《信息检索与科技写作》课程，使用本脚本可以全自动播放视频，并强制调整倍速，建议浏览器为edge和Chrome
脚本文件：`changjiang-video-helper.user.js`

## 安装

1. 在浏览器的 Tampermonkey（油猴）菜单中打开“管理面板 / 仪表盘”。
2. 点击“添加新脚本”，删除编辑器里的默认内容，粘贴脚本文件的全部内容，保存。
3. 刷新 `https://changjiang.yuketang.cn/` 的课程视频页面。
4. 页面右下角出现“连续播放助手”后，点击“播放 / 继续”。

若浏览器提示需要允许用户脚本运行，按扩展提示开启权限后刷新

## 使用

- **失焦保护**：找到页面中的主要视频后，脚本在辅助开启期间屏蔽窗口失焦、页面可见性变化和鼠标离开窗口产生的相关通知，同时向页面报告视频所在文档可见。
- **最高 16× 倍速**：在助手的“倍速”下拉框选择 0.5、1、1.25、1.5、2、3、4、6、8、12 或 16×。选择后会自动开启“锁定倍速”，并记住所选速度。新视频加载、自动下一节或刷新后，会尝试沿用该速度，请注意**过高速度会导致视频无法播放**，别太贪，实测3x可正常在edge中使用。
- **锁定倍速**：开启时，脚本会尝试阻止播放器把速度重设为 1× / 2×；取消勾选后，可以使用原播放器的倍速菜单。面板显示浏览器报告的当前速度，原播放器菜单的文字不用管，进度检测与此无关。停止辅助后也会解除倍速约束，保留已设置的速度和你的选择。
- **暂停处理**：保留普通暂停；只对紧接着失焦发生的暂停尝试恢复一次。发现常见弹窗时不恢复播放。
- **下一节**：收到视频的 `ended` 事件后等待两秒，再点击页面上可见、可用且明确写着“下一节”“下一个视频”“下一课”等文字的唯一按钮。不把“下一题”当作下一节。
- **页面已经自行连播**：如果等待期间视频源或页面地址变化，取消原来的切换任务。
- **停止辅助**：停止当前视频、关闭失焦保护并取消待执行的自动切换。点击“启用辅助”或“播放 / 继续”恢复。
- **自动下一节复选框**：可单独关闭结束后的自动切换。

## （必看）针对《信息检索与科技写作》的内容

1. 在课程目录中找到真实的“下一节 / 下一个视频”按钮，网页版在完成度的旁边。<br>
<img width="221" height="86" alt="image" src="https://github.com/user-attachments/assets/d17a7d53-1659-4f44-b79b-c054d590ad89" /><br>
2. 点击助手里的“指定下一节按钮”。
3. 点击页面上的那个按钮。此次点击只记住位置，不执行跳转；按 Esc 可以取消指定。
4. 视频结束后，脚本会优先点击指定的按钮。如果当前视频已经结束，会开始两秒倒计时。

如果页面改版、按钮文字变化，或出现“指定的按钮已失效”，重新指定即可；也可以点击“清除指定”恢复自动识别。页面存在多个同名按钮时，脚本会要求指定，避免任意选择。
